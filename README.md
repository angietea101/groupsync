# GroupSync

Prototype: collaborative group event booking.

## Local setup

1. Copy `.env.example` → `.env` and fill values
2. `npm install`
3. `npm run dev`

## Scripts

- `npm run dev` — start dev server
- `npm run build` — production build
- `npm test` — run tests
- `npm run lint` — lint

## Tech

React, Vite, Firebase, GitHub Actions
